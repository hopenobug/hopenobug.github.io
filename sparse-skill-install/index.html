用 git 稀疏克隆从大仓库中安装 skills

发表于 2026-11-24 分类于 AI Coding

脚本地址：https://github.com/hopenobug/sparse-skill-install

问题

安装 agent skills 的标准命令是：

它直接支持 GitHub 仓库和技能筛选。但对大多数仓库，CLI 内部会执行 git clone --depth 1，把整个仓库下载下来再从中挑技能（src/git.ts）；如果仓库带子模块，还会递归拉取。只有少数白名单仓库（vercel、vercel-labs 等）走 GitHub API 的 blob 快速通道，跳过 clone。

而技能仓库通常只有 skills/ 目录是需要的：

所以问题不在「能不能装」，而在下载量：装几个几十 KB 的技能，传输量却随整个仓库体积增长。

解决方案：sparse-checkout + partial clone

git 2.25 起支持 sparse-checkout，可以只 checkout 指定子目录。配合 --filter=blob:none（partial clone，blob 按需拉取），git 只下载声明的路径，对任意仓库可用：

各参数的作用：

参数 作用
--no-checkout clone 后不展开工作区，由后面的 sparse-checkout 控制
--depth 1 只要最新一次提交
--filter=blob:none 元数据照常下载，文件内容（blob）按需拉取
sparse-checkout set 声明需要的目录，checkout 时 git 才拉对应 blob

这样实际传输量只有需要的目录本身。

总结

npx skills add 已经支持从 GitHub 仓库直接安装，仓库小的时候用它就够了；白名单仓库走 blob 通道也很快。这个脚本解决的是剩下一种情况：仓库很大、需要的只是其中 skills/ 目录，不想为装技能下载整个仓库。

git sparse-checkout 也适用于其他「只需要仓库中一部分文件」的场景：安装子目录里的工具、读取单个文档、引用示例代码。

脚本约 100 行，依赖 bash、git ≥ 2.25、npx，完整用法说明见仓库 README。
