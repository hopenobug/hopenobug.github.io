c++ concept 备忘

发表于 2026-07-21 分类于 C++

C++20 引入的 concept（概念）是模板编程的一次重大革新。它允许你对模板参数施加编译时约束，明确指定一个类型必须具备哪些属性和行为。

简单来说，concept 就像是模板参数的“接口”或“契约”。你可以定义一些规则，只有满足这些规则的类型，才能被用于特定的模板。
